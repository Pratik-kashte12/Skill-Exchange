# SkillXchange 🎓 — Full Stack Skill Exchange Platform

A MERN stack app where users list skills they can teach and connect with others to learn — barter-based, no money involved.

## Tech Stack
- Frontend: React (Vite) + Tailwind CSS + React Router
- Backend: Node.js + Express
- Database: MongoDB (Atlas)
- Auth: JWT + bcrypt

## Setup

### Backend
```
cd server
npm install
cp .env.example .env   # fill in MONGO_URI and JWT_SECRET
npm run dev
```

### Frontend
```
cd client
npm install
npm run dev
```

Frontend runs at http://localhost:5173, backend at http://localhost:5000
